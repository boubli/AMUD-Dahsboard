AMUD now ships **37 themes** total — 18 brand-new palettes plus a visual **Theme Gallery** built into Settings → Appearance.

<!--truncate-->

## Visual theme picker

No more dropdown + "Load into editor". The Appearance tab now shows a **grid of theme cards** with preview images. Click any theme to instantly preview its CSS and matching wallpaper in the live mini-dashboard. Click **Save Changes** when you're happy.

- **AMUD Default** resets to the built-in orange glass look and `/static/wallpaper.png`
- Every other theme loads its bundled CSS and sets a **matching wallpaper** automatically
- Terminal themes (phosphor, amber, matrix) use CSS-only CRT backgrounds

## New theme packs

### Nature (5)

Aurora Borealis, Desert Dusk, Ocean Depths, Rainforest Mist, Volcanic Ember — totally different moods from the classic developer palettes.

### Terminal (2 new)

Terminal Amber and Terminal Matrix join Terminal Phosphor for CRT lovers.

### Feminine (5)

Sakura Dream, Lavender Mist, Rose Gold Blush, Cotton Candy, Peach Blossom — soft pastels and blossom tones.

### Variety (6)

Nebula Void, Arctic Frost, Steampunk Brass, Zen Garden, Retro Arcade, Midnight City.

## Offline-first

All theme CSS, preview thumbnails, and wallpapers ship inside `ui/static/themes/` on your server. No GitHub Pages required for daily use — the online [Theme Gallery](https://boubli.github.io/AMUD-Dashboard/themes) is there when you want to browse from a browser.

## Try it

1. Update to the latest AMUD build
2. Open **Settings → Appearance**
3. Scroll to **Theme Gallery**
4. Click a theme, then **Save Changes**

Happy theming!
