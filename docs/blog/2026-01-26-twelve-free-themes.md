The default AMUD Dashboard look is orange glass. I like it. My partner said it looked like a Cheetos-themed spaceship cockpit. Fair.

<!-- truncate -->

So I built a [theme gallery](/themes) with twelve ready-made CSS themes and actual dashboard preview screenshots so you can pick before you paste.

## Included themes

Dracula, Nord, Catppuccin Mocha, Azure Calm (formerly Tokyo Night), Gruvbox Dark, Cyberpunk Neon, Solarized Dark, Rose Pine, Everforest, Monokai, One Dark — and later **Ember Hearth** (replaces the old Sunset Warm palette as of v1.8.9).

## Apply one in three clicks

1. Open [/themes](/themes)
2. Hit **Copy CSS**
3. **Settings → Appearance → Custom CSS** → paste → save

Instant. No restart. No import-from-URL (that feature got cut on purpose — copy-paste is safer and works offline).

## Wallpapers too

Each theme has a bundled 2K wallpaper. **Copy wallpaper URL** → paste into background image setting. Makes wall tablets look intentional instead of "sysadmin panel accidentally left on."

Broke the layout with bad CSS? Been there. Recovery guide: [/docs/troubleshooting](/docs/troubleshooting)
